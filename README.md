# 🪔 Ganpati Invitation Website

A modern and interactive **Marathi Ganpati Bappa invitation website** created with React, Vite, Tailwind CSS, and GSAP.

This project combines traditional Maharashtrian aesthetics with a modern web experience, featuring animations, a Ganpati photo, countdown, music, invitation details, Google Maps, and WhatsApp sharing.

> ⚠️ **This project is created for fun, experimentation, and learning purposes only.**
> It is not intended to represent an official religious organization, commercial service, or public event platform.

---

## ✨ Features

- 🪔 Beautiful Ganpati Bappa themed design
- 🇮🇳 Marathi invitation content
- 🎨 Traditional Maharashtrian-inspired color palette
- ✨ GSAP animations and scroll effects
- 🕉️ Animated Ganpati hero section
- 🖼️ Circular Ganpati image
- ⏳ Ganpati arrival countdown
- 🔊 Background Ganpati music with play/pause control
- 📅 Invitation and event details
- 📍 Location and Google Maps integration
- 🧭 Directions button
- 💬 WhatsApp invitation sharing
- 📱 Fully responsive design
- 🌸 Decorative petals and festive elements
- ❤️ Premium-style invitation experience
